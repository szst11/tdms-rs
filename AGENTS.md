# AGENTS.md

## Commands (CI gate on `main`)

Run all three before finishing; CI (`cargo clippy ... -D warnings`) treats warnings as errors:

- `cargo fmt --all -- --check`
- `cargo clippy --all-targets --all-features -- -D warnings`
- `cargo test --all-features`

## Tests

- Two named targets declared in `Cargo.toml`: `cargo test --test golden` (corpus fixtures) and `cargo test --test integration`. Use these to iterate on a single suite; `cargo test --all-features` runs everything.
- Cargo auto-discovers any `*.rs` you drop at the top of `tests/` as an extra integration-test target (e.g. `tests/string_buffers.rs`); the real entrypoints live in `tests/golden_tests/mod.rs` and `tests/integration_tests/mod.rs` subdirs.
- Golden tests open every `.tdms` under `tests/fixtures/tdms_corpus/` and compare against a sibling `.json`. Timestamp channel data is intentionally **not** compared.
- Fixtures are generated by Python scripts in `tools/` (needs `nptdms`; see `requirements.txt`). Regenerate from `tools/` with `python generate_corpus.py` then `python validate_json.py` after format/behavior changes.
- Integration tests write scratch files to `tests/output/` and delete them; `.gitignore` does **not** ignore that dir, so don't commit new files there.

## Architecture

- `src/api/` holds the public reader/writer API, re-exported from `src/lib.rs` (`TdmsFile`/`TdmsGroup`/`TdmsChannel`, `TdmsWriter`/`WriterGroup`/`WriterChannel`).
- `src/format/` is low-level segment/metadata parsing; `src/io/ext.rs` contains little-endian I/O helpers.
- `src/model/` holds data types and the in-memory index (IndexMap).
- Reader: metadata indexed eagerly at `open()`, channel data is lazy and read into caller-provided buffers.
- Writer: staged single-segment writes; file is flushed and closed on drop (RAII), with optional explicit `flush()`. Reader/writer lifetime coupling matters — `WriterGroup`/`WriterChannel` borrow from their parent.
- `src/bin_disabled/` is legacy and excluded from the crate; do not add binaries there.
- `docs/ARCHITECTURE.md` and `docs/API.md` are the canonical deep-dive docs for the design and public API.

## Constraints

- MSRV is Rust 1.70.0, edition 2021 — avoid syntax/APIs newer than 1.70.
- Little-Endian TDMS only.
- No unit tests in `src/`; all correctness testing lives in `tests/`.

## Benchmarking

- The crate declares a `benchmark` binary (`[[bin]]` in `Cargo.toml`); the full suite is driven by `python benchmark/run.py` and expects Windows `diskspd` on `PATH`.
